Aula 12 — Análise de Componentes Principais / PCA

Estudo e simulado discursivo baseado no slide RN-12-PCA.

Roteiro de estudo:
Resumo · Conceitos · Fórmulas · Comparações · Pseudocódigo · Questões · Mini-simulado · Gabarito

1. Resumo essencial

Provável de cair: PCA é uma transformação linear que muda o sistema de coordenadas dos dados para eixos onde a maior variância aparece na primeira componente principal, a segunda maior na segunda, e assim por diante.

A Análise de Componentes Principais identifica padrões nos dados, destacando similaridades e diferenças. Ela também permite compressão e redução de dimensionalidade, preservando a maior parte da informação intrínseca.

O método mais importante dos slides é o método da covariância: organizar os dados, remover a média, calcular a matriz de covariância, obter autovalores/autovetores, ordenar os autovetores por autovalor e projetar os dados na nova base.

2. Conceitos principais que podem cair

  • Redução de dimensionalidade: transformar dados de alta dimensão em menos variáveis.
  • Componente principal: direção/eixo em que a projeção dos dados tem maior variância.
  • Matriz de covariância: mede como variáveis variam juntas.
  • Autovetor: direção que não muda sob uma transformação linear.
  • Autovalor: escalar associado ao autovetor; no PCA representa quanta variância/energia há naquela direção.
  • KLT/Hotelling: transformação que cria uma base ortogonal para representar os dados.
  • Kernel PCA: versão não linear que mapeia dados para um espaço de características usando kernel e aplica PCA linear nesse espaço.
  • GHA e APEX: abordagens neurais/auto-organizáveis para extração de componentes principais.

3. Detalhes “bobos” que o professor pode cobrar

Decorar: PCA maximiza a variância dos dados projetados e minimiza o erro médio quadrado entre os dados e suas projeções.
  • A covariância positiva indica que duas dimensões crescem ou decrescem juntas.
  • A covariância negativa indica que quando uma cresce a outra tende a decrescer.
  • Covariância zero significa variáveis descorrelacionadas, não necessariamente independentes.
  • Autovetores de matrizes simétricas são ortogonais.
  • A matriz de covariância é simétrica.
  • Para reduzir de M variáveis para L, deve-se escolher L < M.
  • Os autovalores e autovetores devem ser mantidos pareados ao ordenar.
  • O índice de energia acumulada ajuda a escolher quantas componentes manter, por exemplo 90%.

4. Fórmulas importantes

Média:
X̄ = (Σ Xi) / n

Valor médio do conjunto de dados.

Desvio padrão amostral:
s = sqrt( Σ(Xi − X̄)² / (n−1) )

Mede o espalhamento dos dados em torno da média.

Variância:
var(X) = Σ(Xi − X̄)(Xi − X̄)/(n−1)

É o quadrado do desvio padrão e mede espalhamento em uma dimensão.

Covariância:
cov(X,Y) = Σ(Xi − X̄)(Yi − Ȳ)/(n−1)

Mede como duas variáveis variam conjuntamente.

Matriz de covariância:
C = (1/(N−1)) B BT

B é a matriz de dados após subtração da média. A matriz C resume variâncias e covariâncias.

Autovalores e autovetores:
A v = λ v

v é autovetor e λ é autovalor. No PCA, os autovetores da matriz de covariância formam os novos eixos.

Projeção PCA:
Y = WT Z = KLT{X}

W contém os L autovetores escolhidos; Z é a matriz padronizada ou de z-scores; Y são os dados projetados.

6. Pseudocódigo

Método da covariância para PCA

Entrada: matriz X com M variáveis e N observações; número L de componentes desejadas.
Organize cada observação como uma coluna da matriz X.
Calcule a média de cada variável e forme o vetor u.
Subtraia u de cada coluna de X, gerando B.
Calcule a matriz de covariância C = (1/(N−1)) BBT.
Calcule autovalores e autovetores de C.
Ordene autovalores em ordem decrescente e reordene os autovetores correspondentes.
Escolha os L primeiros autovetores e forme W.
Opcionalmente calcule z-scores Z.
Projete os dados: Y = WT Z.
Retorne Y e W.

Explicação linha por linha

  • Organizar X: garante que as variáveis e observações estejam na forma esperada.
  • Média u: encontra o centro dos dados.
  • Subtração da média: centraliza os dados na origem.
  • Covariância: revela como as variáveis variam juntas.
  • Autovalores/autovetores: indicam direções principais e sua importância.
  • Ordenação: coloca primeiro as direções de maior variância.
  • Escolha L: reduz dimensionalidade mantendo energia/informação suficiente.
  • Projeção: gera os dados no novo espaço de características.

GHA — Algoritmo Hebbiano Generalizado

Inicialize pesos wji pequenos e taxa de aprendizagem η positiva pequena.
Para cada entrada x(k):
    Calcule a saída de cada nodo yj(k).
    Calcule a variação Δwji(k) pela regra hebbiana generalizada.
    Atualize os pesos.
Repita até os pesos atingirem equilíbrio.
No equilíbrio, os pesos convergem para componentes dos autovetores associados aos autovalores.

Kernel PCA

Escolha uma função de kernel.
Construa a matriz K, onde Kij = K(xi, xj).
Resolva Kv = λv.
Ordene autovalores e autovetores.
Normalize os autovetores.
Projete novos pontos usando os kernels entre o ponto de teste e os pontos de treinamento.

7. Possíveis questões de prova e respostas modelo

Q1. O que é PCA?
PCA é uma transformação linear dos dados para um novo sistema de coordenadas, no qual a primeira coordenada corresponde à direção de maior variância, a segunda à segunda maior variância, e assim por diante. É usado para identificar padrões, reduzir dimensionalidade e comprimir dados.
Q2. Por que PCA reduz dimensionalidade preservando informação?
Porque seleciona as direções que concentram maior variância dos dados. Ao manter as primeiras componentes principais, preserva-se a maior parte da energia ou informação intrínseca do conjunto original.
Q3. Qual é o papel dos autovalores e autovetores no PCA?
Os autovetores da matriz de covariância definem os novos eixos do espaço. Os autovalores associados indicam a quantidade de variância explicada por cada direção. Por isso, os autovetores são ordenados por autovalores decrescentes.
Q4. Explique o método da covariância.
Organizam-se os dados em uma matriz, calcula-se a média de cada variável, centralizam-se os dados, calcula-se a matriz de covariância, obtêm-se autovalores e autovetores, ordenam-se as componentes e projetam-se os dados nos autovetores escolhidos.
Q5. O que diferencia Kernel PCA de PCA linear?
O PCA linear trabalha diretamente em um subespaço linear dos dados. O Kernel PCA aplica uma transformação não linear para um espaço de características e realiza PCA nesse espaço usando funções kernel.

9. Gabarito comentado

  1. Reduzir a dimensionalidade transformando dados para eixos de maior variância, preservando o máximo possível de informação.
  2. Significa que as duas variáveis tendem a crescer ou decrescer juntas.
  3. Autovetor é a direção/eixo principal; autovalor mede a variância/energia associada a essa direção.
  4. PCA linear usa projeção linear; Kernel PCA usa kernel para mapear dados a um espaço de características, permitindo capturar padrões não lineares.
  5. Organizar X; calcular média; centralizar; calcular C; obter autovalores/autovetores; ordenar; escolher L; projetar Y = WᵀZ.
